# Презентация к лекции

## Файлы

- `Offline_iOS_Lecture_LSH.pptx` — **54 слайда**, колода в шаблоне ЛШ2026. Это **источник правды** по составу, порядку и содержимому слайдов. Собирается скриптом.
- `Offline_iOS_Lecture.pptx` — исходная (до-шаблонная) версия колоды, используется как референс контента.
- `Template.pptx` — шаблон ЛШ2026.
- `REVISION_SPEC.md` — спецификация ревизии колоды.

## Сборка

```bash
cd /Users/ilia-ch/SummerSchoolProject
.venv-pptx/bin/python scripts/build_lsh_presentation.py
```

Скрипт пересобирает `Offline_iOS_Lecture_LSH.pptx` из шаблона `Template.pptx`: контент слайдов (заголовки, буллеты, таблицы, код-листинги, заметки докладчика) захардкожен в самом скрипте. Любые правки слайдов вносятся в `scripts/build_lsh_presentation.py`, затем колода пересобирается.

Метки `[СЛАЙД: …]` в `LECTURE_SPEECH.md` повторяют заголовки содержательных слайдов колоды (служебные — содержание, шмуцтитулы, код-слайды — меток не имеют и листаются вместе с ближайшей меткой). Кейс «оффлайн-оплата по BLE» рассказывается без слайда — в речи он помечен `[БЕЗ СЛАЙДА: …]`.

## Формат речи

В `LECTURE_SPEECH.md` два слоя:

- **`[СЛАЙД: …]`** — заголовок слайда, совпадает с колодой
- **`[РЕЧЬ]`** — проговариваешь сам, на экран не попадает

Пометки: `[БЕЗ СЛАЙДА: …]` — рассказ на словах, слайд не переключаем · `[КОММИТ N]` — переключить коммит · `[КОД]` — сниппет · `[ПАУЗА]` / `[ВОПРОС В ЗАЛ]`.
